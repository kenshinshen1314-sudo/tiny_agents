# 研究报告：恒生电子股份有限公司若继续当前的组织变革----裁掉原恒生的老员工，从外部招阿里、华为等大厂输出的中高层管理人才， 大部分不赚钱的业务线搬到武汉，应届生本地化城市都放在武汉。这些外来的中高层管理人员对恒生原有的工程师文化没有归宿感和认同感，而是带来了他们自己原公司的文化和制度，导致现在恒生公司大量的管理层人浮于事，表面文章做的都很好，ppt和方案吹的天花乱坠，实际产品质量越来越差，底下实际干活的人怨声载道，客户也非常不满意。--- 推演恒生公司还能运营多久。
