## 关键实现细节

### 单 Agent 多轮实现

```python
# agent.py 扩展
self.content_agent = self._create_tool_aware_agent(
    name="内容创作专家",
    system_prompt=load_article_style_prompt(),  # 加载 article_style.md
)
```

### 流式输出实现

```python
# main.py
@app.post("/content/generate")
async def generate_content(request: ContentRequest):
    async def generate():
        async for chunk in service.generate_content(
            topic=request.topic,
            platform=request.platform,
            style=request.style
        ):
            yield chunk

    return StreamingResponse(generate())
```

### 错误处理

```python
# 统一错误格式

    "error": "LLM_TIMEOUT",

    "code": 504
}
```

## 架构决策汇总 (已确认)

| 决策点 | 选择 | 理由 |
|-------|------|------|
| Agent 架构 | 单 Agent 多轮 | 与设计文档一致，复现成本最低 |
| API 设计 | `/content/generate` 新端点 | 职责清晰，便于扩展 |
| Prompt 加载 | 启动时加载 article_style.md | 一次加载，重复使用 |
| 错误处理 | 统一错误包装 `{error, code}` | 与现有风格一致 |
| 日志 | 完整日志 | 核心功能需要可观测性 |
| Agent 模式 | 保持独立创建 | 配置不同，避免过早抽象 |
| 测试策略 | 完整测试覆盖 | 质量至关重要 |
| 超时配置 | 支持可配置超时 | 不同内容长度需要不同配置 |
| 并发处理 | 限流 + 队列 (预留) | 当前简单，未来可扩展 |
| 缓存 | MVP 阶段无缓存 | 简化实现，后续按需添加 |
