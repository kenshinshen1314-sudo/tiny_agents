# 任务 3: 影响机制分析

任务概览：分析创作者品味/审美影响作品传播的具体路径与机制
系统提示：需区分直接影响（内容质量）与间接影响（算法推荐、用户互动）
来源概览：传播学理论、算法研究、用户行为数据

## 关键发现

### 1. 算法推荐作为核心中介变量
创作者审美通过平台算法偏好间接影响传播。算法根据停留时长、互动频率推荐内容，作品"被算法认可"优先于"被审美认可"。抖音"兴趣图谱"将用户行为数据转化为推荐依据，使传播不再依赖专业评论或内容水准，而取决于能否快速抓住注意力触发推荐机制。

### 2. 启发式线索优先于系统式线索
实证研究显示第一印象决定传播效果。B 站 325 条科普视频分析表明：标题字数（10 字以下贡献度最高）、封面类型（自主配图显著提升效果）、发布者粉丝量对传播效果影响显著，而内容主题、视频时长等系统式线索影响较弱。用户第一判断很大程度上决定视频传播广度。

### 3. 流量逻辑与审美价值的结构性矛盾
流量作为注意力货币重塑评价体系。胡泳研究指出流量逻辑导致"可测量性"全面渗透，审美经验被简化为数据指标，评价从质性判断转向量化绩效。微短剧 2021-2024 年规模从 3.68 亿飙升至 504 亿，但内容趋同化、审美深度弱化，形成"被多数人喜欢即好"的流量审美。

### 4. 用户互动作为传播放大器
参与度影响算法推荐权重。互动频次 5-20 次对传播效果有显著影响，成就型交互动机贡献度仅次于标题信息。弹幕、评论、分享等行为转化为可交易数据资产，平台将观看、打榜等互动行为量化，实现注意力再商品化，用户参与直接决定作品可见度。

### 5. 创作者声誉资本的累积效应
粉丝量作为信任信号影响传播。实证显示粉丝量多 UP 主视频传播效果更佳（Beta=0.626, p<0.001），且与交互动机存在显著交互作用。布尔迪厄象征性资本理论解释：流量象征被认可的社会地位，创作者声誉形成马太效应，头部创作者凭借初始优势不断积累更多流量。
