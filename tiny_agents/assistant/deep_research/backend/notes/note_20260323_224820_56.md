# 任务 3: 文化心理动机

# 任务概览

**主题**: 为什么年轻人现在都在反消费主义了？
**任务目标**: 探究价值观转变、理性消费觉醒、环保可持续等心理文化动因
**检索查询**: 年轻人消费观转变 理性消费 反攀比 可持续消费 价值观变化

## 来源概览

| 来源标题 | 核心观点 |
|---------|---------|
| 2025年轻人的消费新趋势：体验、悦己与理性消费深度解析 | 青年消费群体呈现全新多元化消费观念，从"悦人消费"转向"悦己消费" |
| 中国年轻人行为方式转防御和理性，"悦己消费"成主流 | 2024年中国20-35岁青年人行为方式趋于防御性和理性化 |
| 2025年消费观念转变与行为趋势全景洞察 | 消费生态从"量"到"质"的觉醒，进入新范式 |
| 从"买东西"到"买感受"——我国青年消费趋势的观察与思考 | 消费从实用功能转向情感满足与心理满足 |
| "情价比消费"浪潮：青年网民的消费观念变迁趋势 | 青年网民消费呈现"情价比"趋势，注重情绪价值 |

## 关键发现摘要

1. **理性消费觉醒**: 年轻人从盲目消费转向精打细算，注重"质价比"
2. **悦己消费兴起**: 从"悦人消费"到"悦己消费"的趋势转变
3. **防御性生存策略**: 外部不确定性环境下形成本能防御
4. **环保可持续意识**: 践行可持续消费理念
5. **情绪价值驱动**: "情价比消费"成为新趋势
