# 任务 1: 基础背景梳理

## 任务概览
- 主题：为什么当代年轻人都不结婚了
- 目标：收集核心背景与最新动态
- 状态：已完成

## 来源概览
本次检索共获取5个信息源，包括知乎专栏、腾讯新闻、搜狐网、澎湃新闻、CEIBS学术文章，涵盖官方民政统计数据、学术研究报告及媒体报道。

## 关键发现
1. **结婚率持续下滑**：2024年全国结婚登记610.6万对，较2023年下降20.5%；2025年第一季度仅181万对，同比再降8.07%
2. **未婚主因非不婚**：调查发现真正不想结婚的仅20.7%，超过40%是因"没合适的对象"
3. **婚恋观念转变**：女性48.6%认为人生不必须结婚，男性48.6%认为必须结婚；48.9%年轻人认为结婚主要目的是"为了爱情"
4. **相亲渠道被忽视**：超四成未婚青年过去一年从未参加相亲；一线城市积极接触异性比例仅23.7%
5. **男女焦虑点不同**：男性更焦虑物质条件（婚房、彩礼准备度均不足30%），女性更担忧婚后生活（婆媳关系、夫妻矛盾等）
