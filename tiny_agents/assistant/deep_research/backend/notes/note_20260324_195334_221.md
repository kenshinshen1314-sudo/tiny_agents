# 任务 4: 风险评估与影响分析

任务概览：评估安全问题的严重程度、影响范围、利用难度
系统提示：分析漏洞等级、受影响系统类型、潜在损失、攻击链
来源概览：风险评估框架、行业报告、专家分析、影响矩阵

任务总结：

## 关键发现

### 1. 系统级权限模型导致攻击面质变
OpenClaw采用自托管架构，直接访问宿主机文件系统、Shell命令执行和API凭证存储，将AI风险从信息层提升至系统层。STRIDE评估显示：权限提升风险为Critical（Rawat et al., 2024），篡改和抵赖风险均为High。相比ChatGPT的云隔离架构，OpenClaw的本地执行权限使提示注入可直接转化为命令执行，威胁等级从Moderate跃升至Severe。

### 2. 供应链污染规模惊人：41%技能含漏洞
ClawSecure对2,890+热门技能审计发现9,515个安全问题，41%含至少一个漏洞，30.6%达HIGH/CRITICAL级别。Bitdefender识别近900个恶意技能（占生态20%），ClawHavoc等4个攻击战役已武器化。99.3%技能无permissions manifest，用户安装前无法知晓系统资源访问范围，形成"盲信安装"风险模式。

### 3. 135,000+实例互联网暴露，默认配置致命
SecurityScorecard STRIKE团队扫描发现超135,000个OpenClaw实例暴露于公网，数小时内从40,000增至135,000。根因：默认绑定0.0.0.0:18789而非127.0.0.1。多数实例运行未 patched 旧版本，15,000+实例可直接远程代码执行，53,000+实例与先前泄露活动关联。部分Bot标签含真实姓名和公司标识，无意暴露访问所有权。

### 4. 三个关键CVE均含公开利用代码
CVE-2026-25253（CVSS 8.8）：一键远程代码执行，窃取认证令牌获取Agent完全控制权；CVE-2026-25157（CVSS 7.8）：macOS应用SSH命令注入；CVE-2026-24763（CVSS 8.8）：通过PATH操纵实现Docker沙箱逃逸。三者均于v2026.1.29修复，但多数暴露实例仍运行旧版本。沙箱逃逸使本应 containment 的Agent行动可完全 bypass。

### 5. "致命三要素"使AI Agent天生脆弱
Palo Alto Networks定义AI Agent风险"致命三要素"：私有数据访问+未信任内容暴露+外部通信能力。OpenClaw同时具备三者：可读取~/.clawdbot/.env中明文API密钥，处理邮件/网页等外部嵌入内容，并能主动外联。MAESTRO框架7层分析显示，会话日志存储完整对话历史、sessions_send工具可作隐蔽通道跨隔离会话协调攻击，形成持久化横向移动路径。

## 缓解建议

1. 沙箱/容器化部署，最小权限执行策略
2. 零信任网络分段，强制127.0.0.1绑定
3. 凭证存入安全密钥库，禁用明文存储
4. 所有外部输入验证注入攻击
5. 启用详细审计日志，监控异常行为
6. 使用ClawSecure等工具预扫描技能
