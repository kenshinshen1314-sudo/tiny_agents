# 任务 4: 社交媒体影响

## 任务概览
- **任务主题**: 为什么年轻人现在都在反消费主义了？
- **任务名称**: 社交媒体影响
- **任务目标**: 考察社交平台、网红经济、内容传播对反消费主义风潮的推动作用
- **检索关键词**: 反消费主义、社交媒体、省钱博主、豆瓣小组、小红书、理性消费

## 来源概览（共4条）

### 1. 万方数据 - 学位论文
- **标题**: 社交媒体参与对极简主义消费意愿的影响研究--以豆瓣消费主义逆行者小组为例
- **核心内容**: 豆瓣上的反消费主义小组在新冠肺炎疫情背景下于互联网空间中迎来了爆发，针对反消费主义感兴趣的个体依托豆瓣平台聚集成能够进行信息交流、情感交流的反消费网络趣缘社群。

### 2. 百度学术 - 硕士学位论文（2022）
- **标题**: 网络趣缘群体反消费主义研究 ————以豆瓣反消费主义小组为例
- **核心内容**: 运用消费的三相理论和自我理论分析网络趣缘社群的反消费主义现象。

### 3. 《国际新闻界》期刊（2023）
- **标题**: 消费主义逆行：基于豆瓣反消费主义小组的网络民族志观察
- **作者**: 董天策、何璇
- **核心内容**: 反消费主义文化反映了部分青年群体的反思性觉醒和文化实践。

### 4. 知乎专栏
- **标题**: 豆瓣"反消费主义"小组存在的原因
- **核心内容**: 年轻人更加追求精神满足，倾向体验式消费（旅行、文化活动、学习新技能），注重自我修养和长久的幸福感。

## 关键发现
1. 豆瓣反消费主义小组在疫情背景下爆发式增长，成为典型趣缘社群
2. 社交媒体平台形成反消费信息交流与情感支持的网络社群
3. 反消费主义反对将个人幸福等同于物质过度购买
4. 年轻人更追求精神满足，倾向体验式消费以获得长久幸福感
5. 社群传播与"不买日"等文化符号推动反消费主义风潮扩散
