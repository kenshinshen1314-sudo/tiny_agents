# 任务 2: 数据分析

任务概览：收集OpenClaw已知漏洞、CVE记录、安全公告及真实攻击案例
系统提示：重点关注安全数据库、漏洞披露平台、安全研究论文、事件报告
来源概览：CVE数据库、NVD、GitHub Security Advisories、安全厂商报告、黑客社区

## 关键发现汇总

### 1. 漏洞规模与严重程度
截至2026年3月11日，已披露82个CVE漏洞，其中高危33个、中危47个。CVE-2026-25253（CVSS 8.8）可实现一键RCE，CVE-2026-24763为Docker沙箱命令注入。厂商已发布v2026.3.11修复40余个漏洞。

### 2. 暴露面风险
公网暴露实例超46.9万个（活跃20.3万），27.2%存在高危漏洞。SecurityScorecard统计9.5%实例可被直接接管，默认端口18789常被错误配置为0.0.0.0监听。

### 3. 供应链投毒
ClawHub插件中心约20% Skills为恶意或可疑，ClawHavoc行动注入1184个恶意Skill，伪装成加密工具、YouTube总结器等，实为Vidar窃密木马变种。

### 4. 凭证存储缺陷
API密钥、OAuth token、WhatsApp/Telegram凭证以明文存储于~/.openclaw/目录的Markdown和JSON文件中，主机失陷即导致大规模凭证泄露。

### 5. 官方预警与行业响应
工信部NVDB于2026年2月5日发布专门预警；SMU等多所大学发布禁用通告；22%受监控企业发现员工私自"影子部署"行为。
