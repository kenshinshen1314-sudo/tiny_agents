# 研究报告：深度研究 openclaw 引发的宿主机安全问题

# OpenClaw 宿主机安全研究报告要点

## 核心结论
1. **供应链投毒为首要威胁**：20% 技能市场内容为恶意，341-1184 个恶意 Skills 被识别
2. **架构缺陷导致高危 RCE**：CVE-2026-25253（CVSS 8.8）可绕过本地隔离，打破"本地部署=安全"认知
3. **大规模公网暴露**：46.9 万累计暴露实例，27.2% 存在高危漏洞，9.5% 可直接接管
4. **凭证明文存储风险**：~/.openclaw 目录明文存储 Token/密钥，Vidar 木马定向狩猎
5. **根本性架构瓶颈**：Transformer 无法区分指令/数据，需神经网络级隔离方案

## 关键数据
- 82 个 CVE 漏洞（33 高危/47 中危）
- 23 万 + 实例暴露，39% 泄露率
- 22% 企业存在影子部署
- 工信部 2026.2.5 发布官方预警

## 优先建议
1. 立即更新至 v2026.3.11+
2. 容器/虚拟机隔离部署，禁止 root 运行
3. 技能白名单 + 凭证加密
4. 管理端口仅绑定 localhost + 强认证
5. 推动架构级指令/数据分离方案
