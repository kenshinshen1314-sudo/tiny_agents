# Tiny Agents 项目代码结构分析

## 项目概述
Tiny Agents 是一个轻量级 Python AI Agent 框架，提供多种 Agent 范式、工具系统、记忆管理、上下文工程和通信协议支持。

## 主要目录结构

### 核心模块 (core/)
- agent.py (43KB) - Agent 基类和核心逻辑
- llm.py (17KB) - LLM 调用封装
- llm_adapters.py (23KB) - 多 LLM 提供商适配器
- session_store.py (7KB) - 会话持久化
- config.py - 配置管理

### Agent 实现 (agents/)
- simple_agent.py - 简单对话 Agent
- function_call_agent.py - 函数调用 Agent
- react_agent.py - ReAct 推理 Agent
- plan_solve_agent.py - 规划执行 Agent
- reflection_agent.py - 反思 Agent
- tool_aware_simple_agent.py - 工具感知 Agent
- factory.py - Agent 工厂

### 工具系统 (tools/)
- base.py - 工具基类
- registry.py - 工具注册表
- chain.py - 工具链
- builtin/ - 内置工具集
  - file_tools.py - 文件操作
  - calculator_tool.py - 计算器
  - search_tool.py - 搜索
  - terminal_tool.py - 终端
  - note_tool.py - 笔记
  - memory_tool.py - 记忆
  - rag_tool.py - RAG
  - task_tool.py - 子代理
  - 等等

### 记忆系统 (memory/)
- base.py - 记忆基类
- manager.py - 记忆管理器
- embedding.py - 向量嵌入
- storage/ - 存储后端
- types/ - 记忆类型定义

### 上下文工程 (context/)
- builder.py - 上下文构建器
- history.py - 历史管理
- token_counter.py - Token 计数
- truncator.py - 截断器

### 通信协议 (protocols/)
- mcp/ - Model Context Protocol
- a2a/ - Agent-to-Agent Protocol
- anp/ - Agent Network Protocol

### 示例与应用 (demo/, assistant/)
- 多个场景的示例代码
- 预构建的 Assistant 实现

### 其他目录
- tests/ - 测试代码
- docs/ - 文档
- evaluation/ - 评估模块
- models/ - 模型相关
- observability/ - 可观测性
- rl/ - 强化学习
- data/ - 数据目录
